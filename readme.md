# Austrian Macroeconomic Dynamics: Phillips Curve & Output Gap Analysis

## Overview
This repository contains an econometric analysis of Austria's macroeconomic indicators, specifically focusing on real GDP and inflation from 1920 onwards. The project evaluates the historical relationship between the output gap and inflation through various models of the Phillips Curve, adjusting for severe historical volatility such as the 1921-1922 Austrian hyperinflation period, the 1930s depression, and World War II. 

All core analysis, data extraction, and visual outputs are executed via `aurtria_phillips_curve_analysis.R`.

## Data Source
*   **Database:** Global Macro Database (GMD)
*   **Vintage/Version:** 2026_03
*   **Variables Extracted:** Real GDP (`rGDP`) and Inflation (`infl`) for Austria (`AUT`)

## Methodology
The analysis is structured into five sequential tasks:

*   **Task A: Data Cleaning & Summary Statistics:** Filters historical data from 1920, calculates the log of real GDP, screens for extreme inflation outliers (identifying the >50% hyperinflation bounds), and generates baseline summary statistics.
*   **Task B: Output Gap Estimation:** Computes the output gap using three distinct filtering techniques to compare methodological differences:
    *   Hodrick-Prescott (HP) Filter (Baseline $\lambda = 100$; Sensitivity $\lambda = 6.25$).
    *   Hamilton Regression (Manual implementation using $t-2$ through $t-5$ lags).
    *   Christiano-Fitzgerald (CF) Band-Pass Filter.
*   **Task C: Phillips Curve Modeling:** Evaluates the inflation-output gap relationship across three theoretical frameworks:
    *   Static Phillips Curve (evaluated with classical and Newey-West HAC standard errors).
    *   Accelerationist Phillips Curve (optimized via AIC across 1 to 4 lags).
    *   Hybrid New Keynesian Phillips Curve (estimated via Instrumental Variables using lagged inflation, lagged gap, and lagged economic growth).
*   **Task D: Diagnostics & Structural Breaks:** Validates model robustness using stationarity tests (ADF, PP, KPSS), residual diagnostics (Breusch-Godfrey, Breusch-Pagan, Jarque-Bera, RESET), and identifies historical regime changes using OLS-CUSUM paths and Bai-Perron breakpoints.
*   **Task E: Visualizations:** Generates a 300-dpi scatter plot of the Phillips Curve, categorized by major historical epochs (Interwar, WWII/Post-War, Bretton Woods, Stagflation, Great Moderation, Post-Crisis, Pandemic+).

## Prerequisites
To run `aurtria_phillips_curve_analysis.R`, you will need R installed along with the following packages:
*   `dplyr`, `tidyr`, `ggplot2`
*   `lmtest`, `sandwich`, `car`, `AER`
*   `urca`, `tseries`, `strucchange`, `moments`, `mFilter`
*   `stargazer`
*   `globalmacrodata` (Installed via `remotes::install_github("KMueller-Lab/Global-Macro-Database-R")`)

## Repository Structure
*   `aurtria_phillips_curve_analysis.R`: The primary execution script containing all data processing, modeling, and plotting logic.
*   `data/`: Directory generated locally by the script to store `raw_AUT.csv` and `clean_AUT.csv` to avoid absolute path dependencies.
*   `figures/`: Directory generated by the script containing output visualizations, including `fig4.png`.
